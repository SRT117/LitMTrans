# MTranServer 与翻译模型

Windows 安装包包含 [MTranServer 4.0.33](https://github.com/xxnuo/MTranServer)，采用 Apache-2.0 许可证；许可证见 `LICENSE-Apache-2.0.txt`。

随包提供的英译简中模型来自 [Mozilla Firefox Translations models](https://github.com/mozilla/firefox-translations-models)，采用 MPL-2.0 许可证；许可证见 `LICENSE-models-MPL-2.0.txt`。

正式发行只打包 `litmtrans.spec` 中 `MTRAN_RELEASE_MODELS` 明确列出的语言目录。
